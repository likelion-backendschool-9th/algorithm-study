## [모의 코딩테스트]
* **일시**: 2026.10.05(월) 10시 30분
* **진행**:
  * **10:30 ~ 11:00** : 응시 환경 및 주변 점검, 풀이 용지(A4 용지 2매) 확인
  * **11:00 ~ 13:00** : 시험 응시
  * **13:00 ~ 13:20** : 주변 환경 점검 및 시험 종료
* **URL**: [프로그래머스 샘플 문제](https://programmers.co.kr) (모의고사 1회)


<br/>

## [응시자 매뉴얼]
1. **준비물**: 앞뒤 인쇄가 없는 빈 A4 용지 2장 이내, 볼펜 2자루
2. **주변 환경**: 
   * 서브 모니터는 불투명한 담요나 천으로 가린 채, 메인 모니터 1개로만 응시합니다. 
   * 디스코드 화상 회의를 통해 캠을 켠 후 입장합니다. 
   * 책상 위 풀이 용지와 볼펜 이외의 다른 물건은 두는 것을 금합니다. 
   * 사방이 막힌 독립되고 정숙한 공간에서 참여합니다. 
3. **일정 변경**: 
   * 부득이한 사정으로 시간 변경이 필요한 경우, 변경 희망 시간과 사유를 스터디 디스코드방에 제출 (2026.10.03 오후 11:59까지)
   * 이후 모든 인원(지혜, 덕관, 주상)의 동의가 이뤄질 경우에만 시험 시간이 변경됩니다. 
4. **부정행위 금지**: 올바르고 건전한 시험 문화를 위하여 인터넷 검색 및 AI 사용과 같은 부정행위를 금합니다.
