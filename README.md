## 📂 폴더 구조 및 파일명 규칙

문제를 제출할 때는 타인과 코드가 섞이지 않도록 아래 규칙을 준수합니다.

### 폴더 구조
```text
플랫폼_이름 / 문제_이름 / 소스코드파일
```
* 예시: `week01/Programmers_기능개발/Jihye.java`
* 예시: `week01/Baekjoon_2557/Jihye.py`

### 파일명 규칙
* `[이름].[확장자]` (예: `Jihye.java`, `Jihye.py`, `Jihye.cpp`)
